## Introducción

En esta actividad he practicado diferentes operaciones básicas de Git y GitHub, trabajando con un repositorio mediante fork, clonación, ramas, commits, push, merge y Pull Request.

## 1. Fork del repositorio

Realicé un fork del repositorio original proporcionado por el profesor para disponer de una copia propia del proyecto.

## 2. Instalación y comprobación de Git

Instalé Git y comprobé que estaba correctamente instalado mediante:

`git --version`

La versión obtenida fue 2.56.0.windows.1.

## 3. Clonación del repositorio

Cloné mi fork de GitHub en mi ordenador mediante el comando `git clone`.

## 4. Comprobación del repositorio

Comprobé mediante `git status` que el repositorio estaba en la rama `main` y que no había cambios pendientes.

## 5. Creación de la estructura

Dentro de `entregas` creé mi carpeta personal `alejandro.pelayo` y dentro de ella la carpeta `AEC-GIT`.

## 6. Creación del archivo inicial

Dentro de `AEC-GIT` creé el archivo `README.md`.

## 7. Creación de la rama de modificaciones

Creé la rama `docs/modificaciones` para realizar los cambios y documentar el proceso de la actividad.

## 8. Evidencias

Las capturas de pantalla realizadas durante el proceso se encuentran en la carpeta `capturas`.

## 9. Trabajo con Git

Durante la actividad utilicé comandos básicos de Git como `git clone`, `git status`, `git add`, `git commit`, `git push`, `git checkout` y `git merge`.

## 10. Merge y Pull Request

Finalmente, la rama de modificaciones se fusionará con `main` y se realizará el Pull Request hacia el repositorio original.
